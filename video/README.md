# DiffDodree 소개 영상 (16:9)

GitHub 저장소에서 논문을 소개하기 위한 약 7분 30초짜리 가로 영상입니다. 논문 4.1–4.6절과 6.1절의 흐름을 음악 연구자가 읽기 쉬운 말로 옮겼습니다.
그림은 [Manim Community](https://www.manim.community/)로 그립니다. 악보는 [Verovio](https://www.verovio.org/)로 오선보를 새기고, 음표 아래에 율명을 답니다.
목소리는 기기 안에서 도는 한국어 TTS [Supertonic](https://github.com/supertone-inc/supertonic)으로 만들며, 대본을 인터넷으로 보내지 않습니다.

## 만들기

```bash
uv venv ~/.venvs/manim-ko --python 3.12 && source ~/.venvs/manim-ko/bin/activate && uv pip install manim supertonic soundfile scipy verovio
```

```bash
node video/extract_manifold.mjs 1000 1000 diffusion_graph_010 0
```

```bash
bash video/build.sh preview
```

```bash
bash video/build.sh
```

- 결과: `video/output/diffdodree_explainer.mp4` (1920×1080, 30 fps, −16 LUFS).
- 목소리 바꾸기: `VOICE=M1 SPEED=1.0 bash video/build.sh` (F1–F5, M1–M5; 기본 F1, 1.0배속).
- 대본 고치기: `video/narration.py`에 읽는 말과 자막을 따로 적습니다. 바뀐 줄만 다시 합성합니다.
- 한 장면만: `manim -r 960,540 --fps 15 video/explainer.py S07_Manifold`
- 악보: `video/score.py`가 마디를 ABC로 적어 Verovio로 새기고, 음표마다 율명을 답니다. 조표는 내림표 셋(黃 = E♭)입니다.
- 필요한 것: ffmpeg, Node 18+, macOS의 Apple SD Gothic Neo 글꼴. 소리는 웹 데모와 같은 합성음이며 피리 녹음이 아닙니다.
