# 연구 질문 초안 v0.1 (2026-09-29, 김명옥 박사님 논의용)

상태: 초안입니다. 아래 "박사님께 여쭙고 싶은 것"의 답에 따라 정의와 실험이 바뀝니다.

## 1. 배경 (한 단락)

국악처럼 악보 수가 매우 적은 전통음악에 대량 데이터 기반 생성 모델을 적용하면, 결과물은 나오지만 그 음악을 그 음악으로 만드는 구조가 흐려질 수 있다. 이 연구는 도드리 계열의 대표적 구조 원리인 **환입(還入, 앞의 선율로 되돌아 들어감)**을 대상으로, 양청도드리 한 곡의 악보만으로 학습한 생성 모델이 환입을 유지하면서 새로운 악보를 만들 수 있는지 검증한다. "철학"이라는 표현은 쓰지 않고, 전문가가 규정한 구조 관계를 관찰 가능한 형태로 다룬다.

## 2. 연구 질문

> **도드리의 환입 구조를, 소량 데이터의 단일 악보로 학습한 생성 모델이 원곡을 복사하지 않고도 보존할 수 있는가?**

여기서 "보존"은 생성 후 복사로 강제한 것이 아니라, 모델의 출력에서 관찰된 것을 뜻한다. "원곡을 복사하지 않고도"는 새로 만든 제1장에 대해서도 제4장이 그것을 되풀이하는지를 포함한다.

**결과를 해석하는 기준.** 제1장을 제4장에 복사하는 규칙(R1)은 환입을 100% 만족한다. 따라서 학습 모델의 결과는 규칙 기반 기준선(R0·R1·R2)과 비교해, 같은 새로움 수준에서 이 곡의 양식에 더 잘 맞는 선율을 만드는지로 해석한다. 차이가 없다면 "규칙만으로 충분하다"고 보고한다.

**부가 분석 (논의 후 결정).** 같은 데이터에 TDA(기존 연구의 overlap matrix)를 적용했을 때 환입이 사이클 구조로 드러나는가.

**후속 연구로 두는 것.** 전문가가 환입이 깨진 악보를 알아채는지 확인하는 평가, 다른 도드리 곡으로의 확장.

### 하위 연구질문

- **SQ1.** 원곡의 환입 구조를 어떻게 정량화할 것인가?
  - 세 요소로 답한다: (i) 관계의 정의(어느 구간이 어느 구간으로 되돌아오는가), (ii) 강도(되돌아온 구간이 얼마나 같은가), (iii) 특이성(그 되풀이가 이 곡에서 얼마나 두드러지는가). 마디 군집 전이 그래프(phrase graph)는 이 정량화의 귀무 모델과 곡의 문법(SQ5)에 쓴다.
- **SQ2.** 환입 구조가 보존되었다는 것을 어떻게 측정할 것인가? 원곡 복사와 구조 보존을 어떻게 구별할 것인가?
  - 구별할 대상: (a) 원곡 또는 환입이 있는 절을 그대로 가져온 것, (b) 새로 만든 재료를 환입 구조로 되풀이한 것, (c) 환입과 무관하게 우연히 같아진 것. 보존으로 인정하는 것은 (b)뿐이다.
  - 측정은 두 값의 쌍이다: (i) 생성물 안에서 제4장이 제1장을 되풀이하는 정도, (ii) 그 제1장이 원곡과 다른 정도.
- **SQ3.** 새로 만든 재료에서도 환입이 보존되는가? 새로움을 높이면 보존이 깨지는가?
- **SQ4.** 환입 보존은 어디서 오는가? (학습 시 정보, 생성 시 정보)
- **SQ5.** 규칙 기반 방법 대비 학습은 무엇을 더하는가?

## 3. 데이터에서 확인한 사실 (저장소 `artifacts/measures_v0.json` 기준)

1. **제1–4마디와 제25–28마디는 음높이와 길이까지 완전히 같다.** 이 곡의 피리 파트에서 환입은 4마디의 정확한 반복이다.
2. **이 곡은 원래 반복이 많다.** 72마디 중 서로 다른 마디는 51개뿐이고, 정확히 같은 마디 쌍이 34쌍이다. 제1–4마디에 해당하는 선율은 제8–12마디에도 나타난다(1=11, 2=8=12, 3=9, 4=10). 따라서 "제4장이 제1장과 같다"만으로는 환입 보존의 증거가 되지 못할 수 있다. 우연히 같아진 경우와 구별하는 기준이 필요하다.
3. **마디는 9개의 군집(A–I)으로 묶여 있고, 제1장과 제4장은 둘 다 A-A-A-A이다.** A는 전체 마디의 약 24%를 차지하므로, 군집 수준의 일치는 환입의 약한 증거이다. 판정은 음높이·길이의 표면 일치로 해야 한다.
4. **음높이·길이까지 같은 4마디 이상의 반복은 곡 전체에서 (제1–4마디, 제25–28마디) 하나뿐이다.** 3마디 반복은 4쌍, 2마디 반복은 11쌍이고 5마디 이상은 없다. 군집 수준(A-A-A-A)으로는 제1, 8, 9, 25마디에서 시작하는 구간이 모두 같아서 환입을 특정할 수 없다. 또 마디 군집 전이 그래프의 1차 확률만으로 제25–28마디가 A-A-A-A일 확률은 약 1.7%(제24마디가 F 군집일 때)여서, 그래프는 환입을 설명하지 못한다. (피리 파트 기준)

## 4. 용어 정의

**마디 군집(cluster)** = 72마디를 서로 비슷한 것끼리 9개로 묶고 A–I 이름을 붙인 것(컴퓨터가 유사도로 묶은 것이며 전문가 분류가 아님). 곡은 이 문자열로 요약된다(예: 제1장 AAAA, 제4장 AAAA). 아래 규칙 기반 방법은 "A 다음에는 어떤 군집이 오는가"의 관측 빈도를 쓴다.

**규칙 기반 방법** = 신경망 학습 없이, 사람이 정한 규칙과 관측된 빈도만으로 곡을 만드는 방법. 세 단계로 구분한다.

| 이름 | 방법 | 용도 |
|---|---|---|
| R0 | 마디 군집의 관측된 전이(A 다음에 무엇이 오는지의 빈도)만으로 군집 순서를 뽑고, 각 군집의 마디 중 하나를 골라 붙임. 환입 규칙 없음 | 환입이 규칙 없이 우연히 나타나는 정도 |
| R1 | R0으로 만든 뒤 제1장을 제4장에 그대로 복사 | 환입은 정의상 100% 만족. 학습 없이 어디까지 되는지의 기준선 |
| R2 | R1에 마디 내 음 교체 등 작은 변형을 넣어 새로움을 조절 | 규칙만으로 새로움과 환입을 함께 얻는 기준선 |

**학습 모델** = 양청도드리 악보 72마디로 학습한 마스킹 기반 생성 모델(현재 구현). 환입 관계를 학습 손실과 생성 유도에 어떻게 쓰는지에 따라 조건을 나눈다.

**새로움** = 생성물의 마디(또는 구간)가 원곡에 없는 정도. 원곡 마디를 그대로 재배열한 것은 새롭지 않다.

**환입 보존(잠정)** = 지정된 두 구간(1–4마디, 25–28마디)의 마디가 음높이·길이까지 같은가. 단, 정의는 박사님과 확정한다.

## 5. 실험 조건

| 조건 | 학습 시 환입 정보 | 생성 시 환입 정보 |
|---|---|---|
| R0, R1, R2 (규칙 기반) | 해당 없음 | R0 없음, R1·R2 있음 |
| 모델: 환입 정보 없음 | 없음 | 없음 |
| 모델: 생성 시에만 | 없음 | 있음 |
| 모델: 학습 시에만 | 있음 | 없음 |
| 모델: 제안 (둘 다) | 있음 | 있음 |
| 범용 모델 (선택) | 해당 없음 | 제1–3장을 주고 이어 쓰기 |

## 6. 측정 (안)

세 가지 축을 함께 본다. 환입 보존만으로는 판단하지 않는다.

1. **환입 보존:** 지정 구간 쌍의 표면 일치율. 대조로, **지정하지 않은 다른 구간 쌍**의 일치율과 비교하여, 환입이 그 자리에서 특별히 나타나는지 본다(3절 2번의 우연 일치 대응).
2. **새로움:** 원곡에 없는 마디 및 구간의 비율. `r_new`(새 제1장에 대한 제4장의 반응)와 `r_copy`(원곡 그대로일 때의 반응)를 분리해 보고한다.
3. **양식 적합도 (미확정):** 생성물이 이 곡의 문법 안에 있는지. 예: 군집 전이가 관측된 범위인지, 음 사이 진행이 원곡 분포와 가까운지, 박 구성이 맞는지.

**핵심 논리:** 환입은 R1처럼 규칙으로 복사하면 100%가 된다. 따라서 학습 모델의 기여는 "환입 보존율"이 아니라 **같은 새로움 수준에서 양식 적합도가 더 높은가**로 판단한다. 이것이 R1·R2와의 실질적인 비교점이다.

## 7. 박사님께 여쭙고 싶은 것

1. 이 곡의 환입은 피리 파트에서 제1–4마디와 제25–28마디가 같은 것으로 충분히 대표됩니까? 다른 악기 파트(거문고 등)에서는 변주가 있습니까? 환입이 원형 반복이어야 하는지, 변주를 허용하는지도 알려주세요.
2. 제1–4마디의 선율이 제8–12마디에도 나오는데(1=11, 2=8=12, 3=9, 4=10), 이것도 환입과 같은 성격의 회귀로 보십니까, 아니면 장 안의 일반적 반복입니까?
3. 환입이 깨지면 "도드리가 아니게 되는" 최소한의 변형은 무엇입니까? (예: 제4장 한 마디만 다른 경우)
4. 새로운 제1장을 만들 때 지켜야 할 최소한의 양식 조건(음역, 사용 가능한 율명, 박 구성, 종지 등)은 무엇입니까?
5. 환입 정의의 표준 문헌과, 도드리 계열 곡별 환입 위치 일람을 주실 수 있습니까? 다른 도드리 곡 악보의 확보 가능 시점과 이용 조건도 함께 알려주세요.
